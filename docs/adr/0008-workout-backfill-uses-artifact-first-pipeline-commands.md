# Workout backfill uses artifact-first pipeline commands

Workout backfill is operated through a top-level `workout-backfill` command backed by a pipeline Module, replacing the older `sync-review` and `sync-apply` backfill command paths rather than preserving aliases. The `review` command is the only command that generates a review directory from a True Coach Workout id; later artifact-reading and mutation commands consume `--review-dir`, with decisions edited as `decisions.json` inside that directory. `write-request` creates a manifest-verified `hevy-workout-request.json`, and mutation commands such as `apply` and `link-workout` submit or link only from manifest-verified request artifacts, trading shortcut regeneration for auditability and artifact integrity. Documentation, skills, prompts, and agent instructions should be updated to teach the new `workout-backfill` paths rather than preserving the old `sync-review`/`sync-apply` backfill paths.
