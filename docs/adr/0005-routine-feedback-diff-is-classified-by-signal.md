# Routine feedback diff is classified by signal

After a Hevy Routine is performed, Hevy can offer to update the Routine from the completed Workout. We treat that post-workout Routine update as a useful feedback loop, but not as a raw source of future prescription truth: rest-period edits, template replacements, notes changes, set-count changes, and set-type changes are reviewable Routine feedback, while pure load changes, pure rep value changes, and performed cardio durations on distance sets are low-signal performed results unless the Athlete explicitly promotes them.

This keeps the agent focused on prescription-shaping decisions without losing the audit trail of what changed. Coach-authored prescription text still wins over Athlete feedback when it is explicit, such as a written `45s rest`; when Coach text is silent, accepted Athlete feedback may become a reusable default for the selected Hevy exercise template.
